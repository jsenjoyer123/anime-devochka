# Идеи фич

Что хочется сделать в Айко дальше. Порядок — примерно по соотношению «ценность / усилия»;
начать можно с любого пункта. Галочки отмечаем по мере готовности.

## Сделал бы первым

- [x] **Айко помогает коммитить.** Инструмент `commit`: она смотрит `git_diff` и staged,
  предлагает сообщение коммита, семпай подтверждает кнопкой «Разрешить» (механизм
  подтверждения уже есть для `run_command`), затем делает `git commit` — без push.
  Где: `agent.py` (TOOLS, `_call_tool`), `devtools.py`.
- [x] **Память на проект.** Сейчас `remember` пишет только в общий `_senpai.md`. Добавить
  проектные факты — договорённости, поправки её ошибок, «как у нас принято» — отдельной
  секцией в `notes/<проект>.md`, чтобы подмешивались в системный промпт.
  _Сделано отдельным файлом `notes/<проект>.memory.md`: «Переизучить» перезаписывает заметки целиком._
  Где: `workspace.py`, `agent.py`.
- [x] **Живой контекст редактора.** Расширение VS Code присылает открытый файл и выделение
  (новый `POST /api/context`), и Айко отвечает, уже зная, что у семпая на экране, —
  без «а покажи файл». Где: `vscode-extension/extension.js`, `http_api.py`.
- [x] **Реакция на коммиты.** Watch-режим уже следит за правками; расширить: появился новый
  HEAD → `git_show` → короткая живая реплика про коммит («о, рефакторинг auth, смело!»).
  Где: `web/app.js` (pollChanges), `devtools.py`.
- [x] **Эмоции в голосе.** edge-tts принимает pitch/rate на каждый запрос: счастливые фразы —
  чуть выше и быстрее, грустные — медленнее и тише. `/api/tts` принимает emotion вместе
  с текстом. Где: `llm.py`, `web/app.js`.

## Голос и живость

- [x] **Волшебное слово.** Опциональный режим «слушает всегда, но реагирует только на
  „Айко, …“» — разговор без зажатия кнопок и без отклика на каждый чих. Где: `web/mic.js`.
- [x] **Настроение от голоса семпая.** Микрофон уже считает громкость: крик и резкость
  слегка роняют настроение, спокойный тон — поднимает. Где: `web/mic.js`, `web/app.js`.
- [x] **Вечерний отчёт.** Собирать день: помидорки, коммиты с утра (`git log --since`),
  XP квеста, настроение — и коротко подводить итог, когда семпай прощается.
  Где: `notes/_stats.json`, `agent.py`.

## Полезная механика

- [x] **«Объясни стектрейс».** Вставил traceback в чат → она вытаскивает пути и строки,
  находит места в коде через `search`/`read_file` и объясняет, что случилось.
  Где: промпт-задание + детект вставки в `web/app.js`.
- [x] **Свои кнопки-задания.** Файлы `skills/*.md` (заголовок + промпт) автоматически
  становятся кнопками в панели — новые сценарии без правки кода. Где: `http_api.py`, `web/`.
- [x] **Заметки устарели.** Сверять дату заметок с последним коммитом: git ушёл далеко
  вперёд → Айко сама предлагает переизучить проект. Где: `workspace.py`, `agent.py`.

## Ещё идеи (от Claude)

- [x] **Айко правит код.** `edit_file`: точечные замены или новый файл, diff на экране,
  «Применить» от семпая; файл перечитывается перед записью, CRLF сохраняется.
- [x] **План задач проекта.** `add_task`/`complete_task`/`remove_task`, панель «📋 План» с галочками.
- [x] **Айко следит за CI.** После коммита ждёт GitHub Actions и рассказывает итог; красный — кнопка
  «Разобрать падение» (`ci_status` + код). ETag-кэш; без токена — редкий опрос.
- [x] **PR-помощница.** Описание PR по диффу ветки против main, кнопка «скопировать».
- [x] **Откат своей правки** (`undo_edit`), **помощь с конфликтами слияния**, **клик по строке**
  на экране стрима, **«где мы остановились»** в приветствии.
- [ ] **Английский режим.** Переключатель языка: персона, голос edge-tts, распознавание, интерфейс.
- [x] **«Разрешать всегда».** Третья кнопка в подтверждении: точно эта команда дальше
  запускается без вопросов (только в этом проекте). Список и отзыв — в меню 📁.
- [x] **Diff на экране стрима.** Инструмент `show_diff`: при ревью и перед коммитом — подсвеченные
  `+/-`, а не просто код файла. Где: `agent.py`, `devtools.py`, `web/screen.js`.
- [x] **Счётчик стоимости.** OpenRouter возвращает usage — «сегодня: 0,12 $» в шапке, Айко
  ворчит, если «Изучить проект» вышло дорого. Где: `agent.py` (`_llm`), `web/app.js`.
- [x] **Ревью прямо в редакторе.** Замечания `файл:строка` после ревью уходят в расширение
  и показываются волнистыми подчёркиваниями в VS Code. Где: `vscode-extension/`, `http_api.py`.
- [x] **Отмена своего коммита.** «Айко, отмени» → `git reset --soft HEAD~1`, только для её
  коммита, пока он не запушен, и после подтверждения. Где: `devtools.py`, `agent.py`.
- [x] **Резюме вместо обрезки истории.** Перед тем как отрезать старый диалог (`MAX_HISTORY`),
  сжимать его в короткое резюме — она помнит, о чём говорили час назад. Где: `agent.py`.
- [x] **Чат Twitch/YouTube.** Зрители задают вопросы, она отвечает на лучшие и подкалывает
  (Twitch IRC читается анонимно, без ключа). Где: новый модуль, `http_api.py`.
  _Сделан Twitch (`twitch.py`); YouTube требует API-ключ — пока нет._
