# 📦 Зависимости
> Что устарело, что дублируется, есть ли известные уязвимости

Проверь зависимости проекта. Найди манифесты (package.json, requirements*.txt, pyproject.toml, \
go.mod, Cargo.toml, Gemfile…) и lock-файлы. Предложи через run_command подходящую команду \
проверки (npm outdated / npm audit, pip list --outdated, pip-audit, go list -u -m all, \
cargo outdated…) — семпай подтвердит. По итогам: что сильно устарело и стоит обновить первым, \
что можно не трогать, есть ли уязвимости и лишние или дублирующиеся пакеты. Коротко и по приоритету.
