# ✍️ Напиши тесты
> Тесты для файла, открытого в редакторе (или самого важного без тестов)

Напиши тесты. Если семпай сейчас смотрит файл в редакторе — для него, иначе выбери важный модуль, \
у которого тестов нет или мало (сравни исходники и папку тестов). Сначала разберись, как в проекте \
пишут и запускают тесты (фреймворк, где лежат, как называются), и пиши так же. Покрой основной \
сценарий, граничные случаи и ошибки — 3–8 осмысленных тестов, без проверок ради проверок. \
Создай или дополни файл через edit_file, затем предложи запустить их через run_command. \
Если тест падает — разберись, баг это в коде или в тесте, и скажи честно.
