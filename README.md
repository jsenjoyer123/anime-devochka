# ✿ Айко-тян ✿

3D аниме AI-витубер в стиле Neuro-sama, которая онбордится в твой проект:
сама изучает кодовую базу, водит экскурсии по коду, делает ревью и болтает голосом —
с эмоциями, жестами и субтитрами.

## Запуск

```bash
cp .env.example .env                      # впиши OPENROUTER_API_KEY
uv venv .venv && uv pip install --python .venv/bin/python -r requirements.txt   # голос
.venv/bin/python server.py ~/path/to/project                         # открой http://127.0.0.1:8765
```

Нажми «✨ Изучить проект» — она пройдёт по коду, сохранит заметки в `notes/<проект>.md`
и переоденется под проект. При следующем запуске она всё вспомнит.

## Что умеет

**Онбординг**
- 🗺 **Экскурсия** — пошагово от точки входа к ядру, код показывает на «экране стрима», в конце — вопросы на понимание.
- 🔍 **Ревью** — смотрит незакоммиченные изменения и разбирает баги, риски и стиль.
- 📄 **ONBOARDING.md** — пишет документ для новых людей в команде (со схемой), можно скачать.
- Читает git: лог, `blame`, самые часто меняемые файлы. Рисует Mermaid-схемы.
- Запускает тесты, сборку, линтер — **только после кнопки «Разрешить»** в чате.
- ✅ **Коммит** — смотрит diff, пишет сообщение в стиле истории проекта; ты правишь его прямо
  в чате и жмёшь «Закоммитить». Push она не делает никогда.

**Живость**
- Жесты: машет, хлопает, задумывается, смущается, кланяется, потягивается, подпрыгивает.
- Следит глазами за курсором, оглядывается. Клик по голове — погладить, по телу — ткнуть.
- Думает вслух, пока копается в коде. Через 3 минуты тишины заговорит сама, через 8 — уснёт.
- Настроение (😊/😒 в шапке) растёт от поглаживаний и похвалы, падает от тычков и грубости.
- Помнит семпая во всех проектах (`notes/_senpai.md`), а договорённости и поправки своих ошибок
  по проекту — отдельно (`notes/<проект>.memory.md`, переживает «Переизучить»). Проекты переключаются кнопкой 📁.
- 👀 Следит за правками и предлагает ревью; заметила новый коммит — коротко его прокомментирует.

**Голос**
- 🎤 — разговор без кнопок: она сама слышит, когда ты начал и закончил фразу.
  Заговоришь или начнёшь печатать, пока она говорит, — замолчит.
- Начинает говорить с первого готового предложения, не дожидаясь всего ответа.
- Эмоции слышно: радостные фразы — выше и быстрее, грустные — медленнее и тише.

**Внешний вид**
- Образ под проект: цвета экосистемы, аксессуар (очки, кепка, наушники, кошачьи ушки, каска,
  берет, бантик, ведьминская и новогодняя шляпы), значок на груди, фон (терминал, космос, кофейня…).
- Сезоны: на Хэллоуин летают летучие мыши, зимой идёт снег, весной — сакура.
- Своя модель для проекта: положи `.vrm` в `web/models/projects/<проект>.vrm`.

## Для стрима (OBS)

Добавь в OBS источник «Браузер» с адресом `http://127.0.0.1:8765/?obs=1` —
это Айко на прозрачном фоне без чата. Она повторяет всё, что происходит в основной вкладке:
субтитры, эмоции, жесты, образ, код на экране. Звук идёт из основной вкладки (захват звука рабочего стола).

## Расширение для VS Code

Айко в боковой панели + команды в контекстном меню редактора:
«Спросить Айко про выделенный код» и «Попросить Айко объяснить этот файл».

```bash
ln -s "$PWD/vscode-extension" ~/.vscode/extensions/anime-devochka.aiko-chan-0.1.0
```

Перезапусти VS Code — в панели слева появится иконка Айко. Сервер должен быть запущен;
адрес меняется в настройке `aiko.serverUrl`.

Расширение сообщает Айко, какой файл открыт и что выделено (только файлы её текущего проекта,
секреты не отправляются), — можно спрашивать «а что делает вот это?» без копирования кода.
Выключается настройкой `aiko.shareEditor`.

## Из чего сделана

- **3D:** three.js + [@pixiv/three-vrm](https://github.com/pixiv/three-vrm), грузятся с CDN.
  Модель — любой `.vrm` (VRoid Studio / VRoid Hub): положи в `web/models/aiko.vrm` или перетащи в окно.
  По умолчанию — sample-модель из репозитория three-vrm.
- **Мозги:** OpenRouter, любая модель с tool calling (`OPENROUTER_MODEL` в `.env`).
- **GitHub:** задачи читаются через REST API; для приватных репозиториев добавь `GITHUB_TOKEN` в `.env`.
- **Голос:** [edge-tts](https://github.com/rany2/edge-tts) (онлайн, текст фраз уходит в Microsoft),
  липсинк по громкости. Распознавание речи — дешёвая аудио-модель OpenRouter (`AIKO_STT_MODEL`).
- **Бэкенд:** Python 3.10+, единственная (необязательная) зависимость — edge-tts.

## Бережёт память

- Никаких локальных нейросетей — LLM, голос и распознавание речи не грузят ноутбук.
- Рендер ограничен 30 FPS и пониженным разрешением, во сне — 10 FPS, во скрытой вкладке стоит.
- Файлы читаются построчно с лимитами, вывод команд пишется во временный файл, история диалога сжимается.
- Mermaid подгружается только при первой схеме; запись с микрофона — не длиннее 30 секунд.

## Разработка

Бэкенд — Python 3.10+ без фреймворков:

- `workspace.py` — песочница файлов и память (заметки, семпай, проекты);
- `agent.py` — персона, задания и цикл tool calling;
- `llm.py` — OpenRouter (LLM, распознавание речи) и edge-tts;
- `http_api.py` — HTTP-сервер и API;
- `server.py` — точка входа.

```bash
.venv/bin/python -m unittest discover -s tests    # тесты бэкенда, модель не вызывается
```

Тесты гоняет CI на каждый пуш (`.github/workflows/tests.yml`).

## Безопасность

- Сервер слушает только `127.0.0.1` и отклоняет запросы с чужих сайтов (проверка Host/Origin).
- Видит только файлы указанного проекта и ничего в нём не меняет — заметки лежат в `notes/`.
- Файлы с секретами (`.env`, `*.pem`, ключи) не читает и в API не отправляет.
- Команды запускаются только после явного «Разрешить»; git — только чтение.
