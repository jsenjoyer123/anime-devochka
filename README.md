# ✿ Айко-тян ✿

3D аниме AI-витубер в стиле Neuro-sama, которая онбордится в твой проект:
сама изучает кодовую базу, пишет заметки и отвечает на вопросы голосом, с эмоциями и субтитрами.

## Запуск

```bash
cp .env.example .env                      # впиши OPENROUTER_API_KEY
uv venv .venv && uv pip install --python .venv/bin/python edge-tts   # голос
.venv/bin/python server.py ~/path/to/project                         # открой http://127.0.0.1:8765
```

Нажми «✨ Изучить проект» — она пройдёт по коду и сохранит заметки в `notes/<проект>.md`.
При следующем запуске она их вспомнит.

## Из чего сделана

- **3D:** three.js + [@pixiv/three-vrm](https://github.com/pixiv/three-vrm), грузятся с CDN.
  Модель — любой `.vrm` (VRoid Studio / VRoid Hub): положи в `web/models/aiko.vrm` или перетащи в окно.
  По умолчанию — sample-модель из репозитория three-vrm.
- **Мозги:** OpenRouter, любая модель с tool calling (`OPENROUTER_MODEL` в `.env`).
- **Голос:** нейросетевой TTS через [edge-tts](https://github.com/rany2/edge-tts) (онлайн, текст фраз уходит в Microsoft),
  липсинк по громкости звука. Без edge-tts — браузерный синтез речи, если он есть в системе.
  Микрофон 🎤 — где браузер поддерживает.
- **Бэкенд:** Python 3.10+, единственная (необязательная) зависимость — edge-tts.

## Гардероб

После изучения проекта Айко переодевается под него: цвета экосистемы, аксессуар
(очки, кепка, наушники, кошачьи ушки, каска, берет, бантик) и значок на груди — `PY`, `RS`, `JS`…
Образ сохраняется в `notes/<проект>.outfit.json`. Можно попросить в чате: «переоденься в Rust-стиле».
Из консоли браузера: `aiko.changeOutfit({name: "…", top_color: "#ce422b", accessory: "cap", badge_text: "RS"})`.

## Бережёт память

- Никаких локальных нейросетей — LLM и голос не грузят ноутбук.
- Рендер ограничен 30 FPS и пониженным разрешением, во скрытой вкладке стоит.
- Файлы читаются построчно с лимитами, `node_modules`/`.git` пропускаются, история диалога сжимается.

## Безопасность

- Сервер слушает только `127.0.0.1`.
- Видит только файлы указанного проекта и ничего в нём не меняет.
- Файлы с секретами (`.env`, `*.pem`, ключи) не читает и в API не отправляет.
